# RouteTill identity

Position: Agent-assisted cross-chain checkout with human approval and verified digital delivery.

The agent proposes. You authorize. RouteTill verifies payment and delivery.

[Canonical positioning, persona and claims](POSITIONING.md). Introduce RouteTill first and Purchase Passport second; reserve ProofFlow for the verification engine in developer explanations. John is an illustrative buyer; buyer and merchant participate in one purchase.

Voice: specific, candid, calm. Say which evidence passed and which is unavailable. Never imply synthetic data is a real transaction.

The original route mark joins an entry path to a receipt corner. Assets: [symbol](../public/brand/routetill-symbol.svg), [wordmark](../public/brand/routetill-wordmark.svg), [favicon](../src/app/icon.svg). The Open Graph image is generated by Next.js at `/opengraph-image`.

Typography is Manrope (SIL Open Font License, self-hosted through Fontsource), with system monospace reserved for exact hashes and code. The UI’s source of truth is [DESIGN.md](../DESIGN.md). Light and dark semantic tokens live in `src/app/globals.css`.

Use navy for structural confidence, persimmon for actions, forest for a check that actually passed, amber for uncertainty or synthetic evidence, and brick for rejected/tampered evidence. Always pair state colors with text or an icon. Keep the mark and text readable without decoration. No trademark clearance is claimed.
